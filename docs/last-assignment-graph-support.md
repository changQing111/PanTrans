# pre→last 分配修正（2026-11-09）

本轮只处理三项：contig同品种判断、图支持的跨品种配组及成员交换、有效原pre hub保留。
SCC→pre的聚类逻辑未改。现有按品种最大主染色体拷贝数建立组数、选择seed品种及每组每品种一个主染色体基因的约束保留。染色体仍为软偏好，尚未重新定义多品种、多染色体、多拷贝分配的生物学目标。

## 行为

1. contig同品种偏好使用当前contig的品种，统一处理参考别名，不再使用循环遗留变量。
2. 每个品种的主染色体基因通过确定性的矩形二分匹配联合放置。评分按以下总量依次比较：
   - 存在直接双向覆盖全部成员的hub的组数；
   - 各组最佳hub可直接双向覆盖的成员数；
   - 组内直接双向边对数量；
   - 与seed染色体一致的成员数。
3. 初次分配后最多8轮重新匹配非seed品种，只接受严格改善的成员交换。seed锚点固定；不是全局最优多品种分区算法。
4. 二次拆簇前，若原pre hub仍在组中、满足主染色体/contig代表资格，并与所有成员直接双向连接，保留该hub及整组。
5. 候选配组与修正contig错误后的原位置配组分别经过二次拆分，以更少组数为先、较少singleton为次选择结果。这个保护作用于每个pre、全局contig回收之前，不声称全局最优。
6. 发现历史同起点gene恢复逻辑可绕过品种/图支持约束：单组快捷路径重新带回已排除的重复gene，或后续无条件补入某组。现在保留所有gene，但恢复时也检查双向hub支持和同品种主染色体占位，不满足时保留singleton。没有删除或合并gene ID。

## 验证范围

- 230项测试、832个子测试通过。
- 二分匹配与小矩阵穷举最优解比较；跨品种错配修复；后到品种触发早期成员交换；原hub保留；缺乏支持时拒绝强行合并；contig当前品种；同起点gene保全及品种约束。
- 五品种和十品种使用原始graph.edges.tsv及pre.cluster，全量只重算last分配；检查无gene丢失或重复、直接双向hub支持、每组主染色体品种占位。
- 未重新比对、未重新生成cDNA/GFF3，旧结果未覆盖。
- 新候选cluster和统计保存在PKU-IAAS：
  `/data/changq/Project/pantrans_test/last_assignment_fix_v3_20261109/`。

## 五品种实际反例

原pre hub `HD6172Chr1AG027000`的8个Chr1A基因原被拆为4组，新规则产生2组：
```
ZM16Chr1AG028200 CSChr1AG029800 ZM366Chr1AG028200
HD6172Chr1AG027000 CSChr1AG029900 ZM16Chr1AG028300 ZM22Chr1AG025000 ZM366Chr1AG028300
```
两组都满足同品种主染色体单拷贝约束及直接双向hub支持。原pre hub在其所在组被保留。
